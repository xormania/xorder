# Verified release ledger

The live ledger exposes current recommendations. Explicit removal declarations
under [`retired-records`](../retired-records/) bind retired records to their exact
byte hashes and original source commits in accepted history. The original
publication facts remain unchanged in that history and public Release assets;
retirement creates no replacement availability or registry mutation.

Publication creates `<family>/<runtime-os>/<image-revision>.json` here after
real behavioral tests, anonymous pulls, exact promotion and source Release
verification. Generated catalog/docs PRs carry these files to master.
Do not create records from proposed Dockerfiles or untested candidates.
The first-release ledger is empty until that process succeeds.
